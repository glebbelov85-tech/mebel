# Витрина мастера (вариант 3)

Лёгкий сайт для клиентов мастера: ссылку шлют в Telegram, WhatsApp, ВК.

- `index.html` - вёрстка, `vitrina.js` - логика, `risunki.js` - нарисованные заглушки вместо фото.
- `dannye.js` - **всё содержимое**: имя, контакты, работы, отзывы, коды заказов, цены расчёта. Сейчас - пример (`shablon: true`).
- `redaktor/` - Мастерская: мастер с телефона добавляет работы (фото уменьшаются и получают водяной знак), рассказ голосом, отзывы, ссылки с кодом заказа, цены. Кнопка "Скачать файлы для сайта" даёт архив `dannye.js` + `foto/`.

## Как выложить содержимое мастера
1. Распаковать архив из Мастерской в `site/vitrina/` (заменит `dannye.js`, добавит `foto/`).
2. Строка в `site/obnovlenie.txt`, `python3 site/build.py . --project src`, коммит, PR.

Если мастер прислал только ссылки на соцсети - заполнить `dannye.js` руками по образцу, фото прогнать через Мастерскую (водяной знак впечатывается в файл).

## Ссылки для клиента
- `vitrina/#rabota=<id>` - одна работа, `vitrina/#story=<id>` - работа как сторис, `vitrina/#otzyv=<код>` - отзыв с кодом заказа.

## Ограничения (сайт статический, GitHub Pages)
- Отзыв клиент отправляет мастеру сообщением, публикует мастер. Код заказа доказывает, что отзыв пришёл по ссылке мастера, но не защищает от самого мастера. Для доверия - ссылки на страницы клиентов и на отзывы в 2ГИС/Яндекс Картах.
- В файле хранится не код, а его отпечаток SHA-256 (16 знаков).
- Водяной знак поверх фото на странице - защита от снимка экрана; от скачивания защищает знак, впечатанный в сам файл (Мастерская делает это сама).
- Мастер не публикует сам: нужен человек с доступом к репозиторию. Самостоятельная публикация - следующий шаг (хранилище с входом).
