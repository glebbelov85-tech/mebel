# Закрытая витрина для Краснодара (вариант 5)

Адрес: `.../mebel/krasnodar/`. Вход только по пин-коду. Внутри: обе витрины (лента - `vitrina/`, путешествие по дому - `dom/`)
с работами мастера, проверка подписей работ, вопросы мастеру, отзыв. Ответы уходят текстом в WhatsApp (номер - в зашифрованных данных), копией или файлом.

## Почему шифрование
Репозиторий публичный, сайт статический. Обычный пин на странице ничего не закрывает: файлы открываются по прямой ссылке.
Поэтому в репозитории лежат только зашифрованные файлы `enc/`:
- `meta.json` - соль и число повторов (не секрет);
- `d.bin` - все тексты (данные витрины, вопросы);
- `<id>.bin` - каждое фото отдельно, имя - HMAC от файла.

Ключ: PBKDF2-SHA256, 600 000 повторов, из пин-кода и соли; шифр AES-256-GCM. Расшифровка - в браузере (Web Crypto, `zamok.js`),
фото отдаёт служебный работник `sw.js` по адресу `f/<id>.jpg`; без него все фото расшифровываются сразу. Пин-код в репозитории не хранится.

Ограничения: лимит попыток на статике надёжно сделать нельзя (зашифрованные файлы можно скачать и перебирать без сайта),
защита держится на длине пина (8 цифр) и медленном выводе ключа. Пауза после 5 неверных попыток - только от перебора руками.
Кто знает пин, может сохранить фото себе. Страницы помечены noindex.

## Как обновить содержимое
Исходники (не в репозитории): `/mnt/project-files/vitrina-vk/` (dannye.js + foto/), вопросы и приветствие -
`/mnt/project-files/krasnodar/voprosy.json`, пин - `/mnt/project-files/krasnodar/pin.txt`.

    node site/tools/zashifrovat-krasnodar.js        # перешифровать enc/
    python3 site/build.py . --project src             # собрать сайт

Новый пин: записать в pin.txt и запустить с `--new-salt` (старый ключ на телефоне мастера перестанет работать).
