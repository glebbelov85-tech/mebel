# Мебельный конструктор

Сайт с инструментами для мебельщика: https://glebbelov85-tech.github.io/mebel/ (GitHub Pages, ветка main, корень)

| Адрес | Инструмент |
|---|---|
| `/` | Главная: все инструменты и последний переданный заказ |
| `/kalkulyator/` | Калькулятор мебели (купе, кухни, любое изделие, описание голосом) |
| `/kalkulyator/demo/` | Тот же калькулятор с пояснениями - показать коллегам |
| `/konfigurator/` | Конфигуратор для клиента - эту ссылку можно отправлять клиентам |
| `/kp/` | КП и договор в PDF |
| `/raskroy/` | Карта раскроя |
| `/zakazy/` | Учёт заказов |

## Как заказ переходит между инструментами

Все инструменты на одном сайте, поэтому у них общая память браузера (localStorage).
Кнопка "Передать заказ" в верхней полоске кладёт текущий заказ в общем формате
(`mebel-order`, см. `src/order-format/README.md`) в ключ `mebel-site-order` и открывает
нужный инструмент с `?from=...`. Тот видит метку и открывает заказ сам.

Данные (заказы, цены, клиенты) хранятся только в браузере пользователя, на сервер не уходят.
На другое устройство - файлом заказа `.mebel.json`.

Конфигуратор - страница для клиента: полоска сайта в нём видна только тому, кто уже
заходил на главную или в другие инструменты в этом браузере. Мастер может скопировать
ссылку на конфигуратор с готовым проектом (`#cfg=...`) - клиент откроет её с любого телефона.

## Как устроен репозиторий

- корень (`index.html`, `kalkulyator/`, ...) - готовый сайт, его отдаёт GitHub Pages с ветки `main`;
- `src/` - исходники инструментов (как они лежат в проекте);
- `site/` - то, что делает из них сайт: `build.py`, общая полоска `shared/`, главная `home/`,
  адаптеры `adapters/` (по одному на инструмент: как отдать и как принять заказ).

Пересобрать сайт после правок:

```
python3 site/build.py . --project src
```

Ничего устанавливать не нужно, только Python 3.
