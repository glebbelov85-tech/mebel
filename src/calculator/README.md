# Калькулятор мебели v2 (исходники)

Артефакт: https://claude.ai/artifact/2SVwTwsvCJtPjY3sGyVuSm (slug 0ba89135-fab6-498a-b9cc-ec0af5439de6, capability downloads).
Сборка: `python3 build.py` склеивает src/style.css + src/body.html + src/*.js (по алфавиту) в dist/index.html. Готовая страница: kalkulyator-mebel-v2.html.

- a_core.js - утилиты, прайс (PRICE_DEF, позиция = {id,g,name,s,u,v,sku,link,m}), материалы = позиции прайса с m {kind,t,sw,sh,css,edge,facade,cut}
- b_engine.js - деталь {name,mat,o,x,y,z,a,b,edge,t?,f?,hd?,mod?,w?}, преобразования, costParts, cutList, stretch ("резиновый" размер)
- c_univ.js - шаблоны "Любое изделие"; d_kupe.js - генератор шкафа-купе; e_kitchen.js - MODLIB (модули кухни), углы, genKitchen
- f_ui.js - состояние S, формы, calc(), эскизы (общая проекция деталей); g_3d.js - three.js 0.187 (ES-модуль, грузится по требованию)
- h_price.js - страница прайса, импорт Excel (SheetJS 0.20.3 через @e965/xlsx c SRI), сохранение файлов; i_lib.js - модули, сохранения, резервная копия, toOrder() в формат mebel-order 1.0
- localStorage: mk2_price, mk2_lib, mk2_saved, mk2_current (старые kupe_* переносятся автоматически)
- Тесты: test/run.js (node, логика), test/pw.js и pw2.js (Playwright; CDN подменяется локальными npm-пакетами)

## Описание словами и демо (2026-11-14)
- j_voice.js - parseSpeech(text): русская фраза -> параметры кухни / купе / шаблона, авторасстановка модулей кухни; окно "Описать словами". Микрофон: capability dictation (только владелец и его организация, Chromium), иначе Web Speech API если страница открыта файлом, иначе диктовка клавиатурой телефона в текстовое поле. Тест фраз: `node test/run.js test/t2.js`.
- Демо: build.py собирает dist/demo/index.html (const DEMO=true - баннер с пояснением). Артефакт демо: https://claude.ai/artifact/LDu756Wkhgvgi1eDM2pyoo (slug 9baaaba0-b3da-4b92-b5fb-4282e419a2e2). При изменениях публиковать оба артефакта.

## Описание словами v2 (2026-11-14)
- j_voice.js: vNorm (числа словами, поправки "нет, 3,5", "не прямая, а угловая", "посудомойка не нужна"), vOrder (клиент, телефон, скидка, предоплата, срок, цвет), vMeasures + vFit (размер по разумному диапазону параметра), parseSpeech -> {mode, rows, asks, warns, got, apply}. rows - выжимка по группам (src: said / def / auto), asks - чего не хватает.
- Распознавание: webSpeechEngine (Web Speech API, на сайте) и claudeEngine (диктовка в артефакте) с одним интерфейсом start/stop/reset/destroy. reset() отбрасывает результаты прошлого сеанса по номеру поколения - после "Очистить" старый текст не возвращается. Автоперезапуск после пауз, на Android по одной фразе (там непрерывный режим дублирует текст).
- Голосовые команды целой фразой: "отмена", "очистить", "собрать", "стоп". Черновик текста хранится в mk2_voice_draft до сборки проекта.
- Тесты: `node test/run.js test/t2.js`, `node test/run.js test/t3.js` (фразы), `node test/pw_voice.js` (окно с поддельным распознаванием).

## Быстрое проектирование (2026-11-14)
- k_edit.js - правки готового проекта фразой (панель "Правка голосом" внизу справа): editProject(text) -> {ok,msg,errs}. Кухня: добавь / убери / замени X на Y / поменяй местами / перенеси (после, перед, на правую стену, левее) / "мойку 600" / длины стен, высоты, отделка. Ряд подгоняется по длине стены (edBalance: место берётся у простых шкафов с полками, в крайнем случае сужаются ящики). Купе: размеры, двери, секции, ящики, штанги. Изделие: размеры и состав. Заказ: клиент, скидка и т.д. "Отмена" - снимок S до правки (ED.undo).
- l_show.js - шаблоны (TPL_BUILTIN - фразы для "Описать словами"; свои - снимок изделия в mk2_tpl) и режим "Показать клиенту" (body.show-client: только цена, 3D и текст для клиента без себестоимости).
- m_photo.js - "Фото замера": фото в IndexedDB mk2_photos (уменьшено до 1600 px), разметка в S.photos; эталонный отрезок задаёт масштаб, отрезок можно отправить в проект (через editProject).
- Новые модули подключаются обёртками setMode/openVoice, f_ui.js и body.html не менялись.
- Тесты: `node test/run.js test/t4.js` (правки), test/pw_edit.js, pw_show.js, pw_photo.js (Playwright).

## Голосовой помощник (2026-11-14)
- k_more.js - расширение editProject. edWhole(t) - команды целиком: справка, "сколько стоит проект", цены из прайса ("сколько стоит петля", "покажи цену на ...", priceFind - нечёткий поиск по PRICE), "прайс загружен?", переходы по вкладкам и видам ("открой прайс", "покажи 3D"), показ клиенту, сохранить, Excel, файл заказа, WhatsApp, "новый расчёт". edMore(c) - части фразы: телефон, монтаж, сроки, наценка, доп. позиции, "цена петли 1500", ручки (кухня: обычные/push/gola, купе: без ручек), углы кухни, цоколь, вырезы, высота пеналов, "замени все X на Y"; edKupeMore и edUnivMore - двери, секции, антресоль, подсветка, ящики, полки, штанги, фасад "400 на 700".
- Чего не понял калькулятор - уходит в MebelSite.voiceNav (site/shared/site.js): переходы между инструментами, "на главную", "назад", "нажми ...", "что здесь можно нажать". На других страницах сайта своя кнопка "Голосом" (#msVoice).
- Ответы озвучиваются (speechSynthesis), выключатель - mk2_ed_mute. Разбор фраз идёт на сайте без сети; распознавание речи браузером (Chrome) требует интернет.
- Тесты: t4.js (K>>/Q>>/C>>/U>>), test/pw_site_voice.js (нужен сервер в корне репо на :8765).
- Голос ответов (site/shared/golos.js, MebelVoice): по умолчанию выключен - ответы текстом. Включается в панели кнопкой "звук": там же выбор голоса (лучший русский выбирается сам: Edge Natural > Google русский > улучшенные Apple) и скорость. Есть заготовка под записи живого голоса (window.MEBEL_GOLOS_CLIPS, папка golos/, MebelVoice.recordList()) - сейчас не используется.
- Одна кнопка "Голосом" (2026-11-14): кнопка вверху и плавающая открывают одного помощника (edOpen, сразу слушает). Новый проект собирается прямо из фразы: edNewBody ("новый проект ...", "сделай ...", "нужна ..."), edLooksNew (фраза начинается с изделия и это другое изделие или проект не трогали) -> edBuild (parseSpeech + выжимка в журнале, "уточните" - кнопки, подставляют фразу). Пока после сборки не было правок, непонятая правкой фраза дописывается к описанию и проект пересобирается ("Дополнил"). Большое окно осталось как "Подробное описание".
- Нестрогий разбор и руководство (2026-11-14): k_syn.js - edSyn (синонимы и разговорные слова: раковина, ПММ, холодос, шкафчики сверху, колонна, вешалка, повесь/воткни...), edRel ("шире на 20 см", "мойку пошире", "кухню длиннее"), edCeil ("верхние до потолка 2,7"), edKitWords ("встроенный холодильник", "духовка в пенале" как правка), edAddMissing ("посудомойка 45", если её нет - добавить), edNote ("столешница под дерево" - в "Цвет и декор"). k_guide.js - окно "Как говорить" (ED_GUIDE: разделы и примеры-кнопки), открывается кнопкой в помощнике или фразой "как пользоваться". Проверка формулировок: test/t5.js.
- Микрофон (2026-11-15): одна кнопка "Голосом" - плавающая (верхняя скрыта); нажатие открывает помощника и сразу включает микрофон. Пока слушает - красная кнопка "Стоп" с пульсацией, строка "Слушаю - говорите...", после фразы "Принял: ...". Причина мигания была в edSpeak: при выключенном звуке он всё равно выключал и включал микрофон после каждой фразы - теперь не трогает. То же в панели сайта (site.js talk). Тест: test/pw_mic.js.

## Отмена и меню детали (2026-11-15)
- n_menu.js: общая отмена (snapUndo/undoLast поверх ED.undo; кнопка "Отменить" #u_undo, Ctrl+Z, подсказка "Убрано: ... · Вернуть" - toastA). Удаление/копия деталей и модулей кухни идут через removePart/dupPart/wallAct со снимком.
- "Добавить деталь" - окно типовых деталей: дверь (в свободное место фасада, иначе делит широкую дверь), полка (в промежуток), ящик (снизу, двери укорачиваются), перегородка, своя деталь. Петли/ручки/направляющие пересчитываются по дверям и ящикам (hwSync).
- Правый клик / долгое нажатие (550 мс) в 3D и на чертеже: openPartMenu. Изделие - убрать, копия, дверь, полка сюда, ящик, перегородка, отменить, вернуть как было; кухня - заменить, дверцы/ящики, шире/уже, левее/правее, пустое место, убрать; купе - полки/ящики/штанга секции, деление двери, число дверей.
- Тест: node test/pw_menu.js (three.js берётся из MK_LIBS).
- Разбор по деталям (o_explode.js): кнопка "Разобрать по деталям" в 3D (и пункт меню). EXP {on, amt, drag}: детали разлетаются от центра и вдоль своей толщины, фасады вперёд; в разобранном виде деталь можно тянуть (только для просмотра, проект не меняется), "Приблизить эту деталь" / двойной клик - камера подлетает (zoomPart). "Собрать" возвращает всё на место.
